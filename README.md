# Kodo mate

A motion prototype of the Kodo mate, the pink K, meant for Kodo's empty states.

**Live:** https://chrissoman.github.io/kodo-mate-prototype/

- It looks around for whatever's missing, pulls faces and blinks.
- Bring the pointer near and it notices you and follows the pointer.
- Touch it and it giggles; wiggle over it for more.
- Click it and it jumps back, surprised.
- Leave the mouse still for 15 seconds and it dozes off.

The cog in the bottom-right corner opens the controls: play a moment, set the reach, and switch between empty-state and large size.

The page is a single `index.html` with no dependencies.
